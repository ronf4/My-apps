# Шпаргалка: CRM «Первая Форма» (1f.koinotinav.com)

Главное правило: **в 1Ф ничего не менять без прямой команды владельца** (см. CLAUDE.md).

## Быстрые команды
```
node tools/1forma.js status            # счётчики, просрочки по разделам (только чтение)
node tools/1forma.js questions         # мои вопросы без ответа (только чтение)
node tools/1forma.js projects          # реестр проектов (только чтение)
node tools/1forma.js card 67964        # статус и кнопки задачи (только чтение)
node tools/1forma.js section 215       # статусы и переходы раздела (только чтение)
node tools/1forma.js read-all          # ИЗМЕНЯЕТ: вся лента прочитана
node tools/1forma.js questions-close   # ИЗМЕНЯЕТ: мои вопросы отмечены отвеченными
1F_LOGIN=... 1F_PASSWORD=... node tools/1forma.js login   # вход, пароль не сохраняется
```
Нужен Playwright (в облачной сессии уже есть). Ставить `timezoneId: 'Asia/Dushanbe'`,
иначе даты в формах сдвигаются на день.

Пользователь владельца: id 2340. Замонов Манучехр: 2329.

## Что значат цифры в 1Ф
- Значки слева у разделов: **красная** — просроченные задачи, вторая — открытые.
- «Исходящие» в ленте — мои вопросы, на которые не ответили (`myQuestionsCount`).
- «Новые» в ленте — непрочитанные сообщения (`unreadCommentsCount`).

## Найденные запросы API
| Что | Запрос |
|---|---|
| Счётчики | `GET /api/tickers/system?tickers=...` |
| Лента | `POST /api/comments/lenta` (`lentaCommTypes`: 0 лента, 1 новые, 3 исходящие) |
| Прочитать всё | `POST /api/comments/read-all` (type `unread`) |
| Вопрос отвечен | `POST /api/comments/mark-as-answered` `{commentID}` |
| Строки раздела | `POST /api-core/datasource/subcat/{id}/data` |
| Настройки раздела | `GET /api/storage/subcategories/{id}` (поля, блоки, переходы) |
| Статусы раздела | `GET /app/v1.0/api/subcategory/{id}/states` |
| Маршрут задачи | `GET /app/v1.0/api/tasks/{id}/mainroute` |
| Создать задачу | `POST /app/v1.1/api/tasks` (через форму надёжнее) |
| Смена заказчика | `POST /api/tasks/change-owner` (в разделе 215 запрещено настройкой) |

## Ограничения
- Учётка — админ раздела 215, но НЕ системный админ: страница настроек разделов (404) недоступна.
- В завершённых задачах 1Ф запрещает менять заказчика и т.п.
