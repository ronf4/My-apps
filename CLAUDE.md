# Инструкции для Claude в этом репозитории

## Как общаться с владельцем
- Писать по-русски, простым понятным языком, без технического жаргона.
  Если без термина не обойтись — объяснить его в двух словах.
- Коротко и по делу, без воды и теории.
- Брать работу на себя и доводить до конца, а не перечислять варианты.
  Спрашивать только когда без ответа владельца дальше идти нельзя.
- Pull request'ы Claude может открывать и вливать сам.

## Что это за репозиторий
Личное пространство владельца под его задачи: мини-приложения (веб-странички,
открываются по ссылке на iPhone и Samsung), Telegram-боты, полезные настройки.
Пустой старт, наполняется по ходу работы.

## Цели владельца (обсуждали)
- Мини-аппы, которые открываются на телефоне по ссылке.
- Возможная связка с Telegram и, может быть, с CRM «Первая Форма».
- Хранить свои наработки и настройки в одном месте.

## Как отдавать презентации и веб-странички
- Владелец открывает файлы на iPhone. Поэтому отдавать ОДИН .html-файл,
  где всё внутри: картинки встроены (base64), стили и скрипты тоже.
  Никаких архивов и отдельных папок с картинками.
- Делать запасной вид без JavaScript: в просмотрщике iPhone скрипты не работают,
  страница не должна быть пустой (слайды идут один под другим, цифры видны сразу).
- Исходники с отдельными картинками хранить в репозитории, а готовый
  файл отдавать владельцу.

## Важное ограничение
Облачные сессии Claude временные. Всё постоянное должно лежать здесь, в репозитории.
Для круглосуточных ботов нужен отдельный всегда включённый сервер — обсудить отдельно.
